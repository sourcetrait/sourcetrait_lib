# ~/.sys/app Applications
*Installation path for self-created scripts and applications*

Symlink or copy the necessary files from the `~/proj` directories.  

Use `~/.config` and `~/.sys/.xdg` for user configuration and XDG data,
respectively.  

## ~/app/bin
*Executables*

## ~/app/lib
*Libraries, modules, includes, et cetera*

## ~/app/share
*Assets*
