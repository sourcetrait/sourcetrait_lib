# ~/.sys System 
*User system*

If an application pollutes `~/` with directories and files by default,
they may be configured to go here (typically via `$env`).

By default, holds:
- XDG directories in `.xdg` (other than `~/.config`).
- Dot-files for Cargo, Git, NPM, NodeJS, Pip, Python, RustUp.
