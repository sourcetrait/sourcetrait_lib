# ~/proj System 
*User administration*

If an application pollutes `~/` with directories and files by default,
they may be configured to go here (typically via `$env`).

By default, holds:
- XDG directories other than `~/.config`.
- Rustup `.rustup` and Cargo `.cargo`

With features, holds:
- Claude
  - `.claude`
  - `.claude/.claude.json`
