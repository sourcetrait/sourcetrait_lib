# ~/app Applications

Installation directory for your self-created scripts and applications.  
Symlink or copy the necessary files from your `~/proj` directories.  
Use `~/.config` and `~/.local` for user configuration and data per XDG specs.  

### ~/app/bin
Executables go here.

### ~/app/lib
Libraries, modules, includes, et cetera go here.

### ~/app/share
Assets go here.
